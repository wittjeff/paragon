The standard `ModalDialog` composition. `StandardModal` passes all of its props through to an underlying `ModalDialog` component providing some limited customization. If you have unique needs, use the `ModalDialog` compound component family directly.

## Basic usage

```jsx live
() => {
  const [isOpen, open, close] = useToggle(false);
  return (
    <>
      <Button variant="outline-primary" onClick={open}>Open standard modal</Button>

      <StandardModal
        title="This is a standard modal dialog"
        isOpen={isOpen}
        onClose={close}
        footerNode={(
          <ActionRow>
            <p className="small">
              <Hyperlink destination="#">Get help</Hyperlink>
            </p>
            <ActionRow.Spacer />
            <Button variant="tertiary" onClick={close}>Cancel</Button>
            <Button>Submit</Button>
          </ActionRow>
        )}
        isOverflowVisible={false}
      >
        <p>
          I'm baby palo santo ugh celiac fashion axe. La croix lo-fi venmo whatever. Beard man braid migas single-origin coffee forage ramps. Tumeric messenger bag bicycle rights wayfarers, try-hard cronut blue bottle health goth. Sriracha tumblr cardigan, cloud bread succulents tumeric copper mug marfa semiotics woke next level organic roof party +1 try-hard.
        </p>
      </StandardModal>
    </>
  )
}
```

## Accessibility

**Status:** documented from source (Paragon 23.x, August 2026). Assistive technology verification pending — see the [Accessibility policy](/guides/accessibility-policy).

`StandardModal` is a preconfigured composition of [`ModalDialog`](/components/modal-dialog) and adds
no interaction of its own. All dialog behavior — `role="dialog"` with `aria-label` from `title`,
focus trap and focus return, scroll lock, <kbd>Escape</kbd> / backdrop dismissal, `isBlocking` — and
the mapping to the [APG dialog (modal) pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)
are inherited and documented, together with the applicable ACT rules, in
[ModalDialog's Accessibility section](/components/modal-dialog#accessibility).

### What StandardModal adds or changes

| Element | Attribute | Notes |
| --- | --- | --- |
| Title | `<h2>` via `ModalDialog.Title` | Rendered automatically from the required `title` prop (also the dialog's `aria-label`), so the dialog's purpose is reachable by heading navigation. |
| Close icon button | Rendered by default | `hasCloseButton` defaults to `true`. The default `closeLabel` is the hard-coded English string "Close" (`STANDARD_MODAL_CLOSE_LABEL`), which bypasses `ModalDialog`'s localized default. |

### Application responsibilities

- Supply a meaningful, localized `title`.
- Pass a localized `closeLabel` — the built-in default "Close" is not run through
  `ModalDialog`'s localized message.
- Give every action in `footerNode` a discernible accessible name, and keep at least one
  keyboard-reachable way to close the dialog when using `isBlocking`.

### Known issues

- Inherited from `ModalDialog`: `aria-modal="true"` is not set on the dialog element —
  [#4402](https://github.com/openedx/paragon/issues/4402), identified in the August 2026
  accessibility audit.
